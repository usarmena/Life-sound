🌊 Life Sound Lite 專案規格說明
1. 專案概述

專案名稱：Life Sound Lite（互動式環境音混音器）

專案架構：採用單一 index.html 檔案（內嵌響應式 CSS 與原生 JavaScript），透過 HTML5 <canvas> 實作高效能即時動態視覺特效，並結合 GitHub Pages 進行雲端部署。

2. 核心功能規格

多音軌混音系統：支援 4 種情境音軌（🌧️ 下雨聲、🔥 營火聲、⌨️ 鍵盤敲擊聲、🌊 海浪聲），使用者可透過獨立滑桿自由調整各音軌音量（0% - 100%）。

隨機無縫輪播機制：每種音軌皆配置 4 個本地 MP3 音檔（如 rain1.mp3 至 rain4.mp3）。當單一音檔播放完畢時 (ended 事件)，系統會自動隨機抽取下一個音檔進行無縫接續播放，消除機械式重複感。

資料持久化 (LocalStorage)：運用瀏覽器 localStorage 技術，自動記憶並儲存使用者當前的音量配置，重新整理網頁後可自動載入上次的偏好設定。

全域播放控制：提供「播放全部 / 暫停全部」主控按鈕，並具備互動後自動解鎖音訊播放的相容處理。

3. Canvas 動態物理視覺特效與滑鼠互動

北歐深海流體海浪（底層）：採用多層次平滑曲線（Sine/Cosine 波形疊加）與「冰冷北歐深海」色調（深墨藍至透光灰藍），模擬海水由內向外湧動的 3D 透視感，其起伏振幅與水位高低會隨海浪音量即時連動。

營火火星噴發與游標擾動（中層）：於畫面底部平均隨機生成橘黃色火星，具備向上浮力、隨機左右飄動與生命週期消散效果；當滑鼠游標靠近時，會對火星產生物理排斥力，使其向四周散開。

沉浸式下雨與游標力場（頂層）：頂層動態繪製下雨效果，雨滴密度與透明度與雨聲音量成正比；結合滑鼠游標力場機制，當雨滴進入游標周邊範圍時會被輕輕撥開、改變落下軌跡。

游標微光與特效開關：滑鼠移動時自帶柔和的半透明微光暈；介面上方亦附有「✨ 特效：開/關」切換按鈕，使用者可隨時自由開啟或關閉 Canvas 動畫，兼顧視覺互動性與效能。
